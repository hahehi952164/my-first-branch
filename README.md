# ✨ 靈感收集所｜我的小天地

一個用來收藏靈感、未完成點子、喜愛事物與創作內容的個人網站。透過單頁式介面分類展示各種內容，讓每個念頭都有地方停留，也方便日後整理、培育與完成。

## 🌟 網站功能特色

- 💎 採用毛玻璃風格卡片、柔和漸層背景及深色主題，營造沉穩且富有層次的視覺效果
- 🌙 支援深色與淺色主題切換，並將選擇儲存在瀏覽器中
- 🧭 提供主頁、各種未完成點子、收藏、創作內容、關於我及未名分頁
- 🖼️ 透過獨立 JavaScript 資料檔動態產生精選卡片與各分類內容
- 📚 支援分類標籤、圖片及可下載附件
- 📄 可供下載的企劃書目前存放於 `files/ideas/Test.docx`
- 💬 每個項目皆可展開留言表單，並透過 Formspree 傳送留言
- 📱 支援桌面與手機版面，並提供響應式導覽選單
- ♿ 包含鍵盤焦點樣式、表單必填驗證及降低動態效果模式支援

## 🛠️ 使用技術

- **HTML5**：建立網站結構與語意化頁面內容
- **CSS3**：負責毛玻璃效果、漸層配色、深淺色主題、動畫及響應式版面
- **JavaScript**：處理分頁切換、主題切換、手機導覽、資料渲染及互動功能
- **GitHub Copilot**：輔助網站設計、程式實作與文件撰寫
- **GitHub Pages**：部署與公開網站
- **Formspree**：處理項目留言表單提交

## 📂 專案結構

```text
my-first-branch/
├── index.html          # 網站主要結構、樣式與互動程式碼
├── idea.js             # 各種未完成點子的資料
├── collection.js       # 收藏項目的資料
├── creation.js         # 創作內容的資料
├── files/
│   └── ideas/
│       └── Test.docx   # 可下載的 Word 企劃書
└── README.md           # 專案說明文件
```

## 🚀 本機預覽

直接以瀏覽器開啟 `index.html`，即可瀏覽網站。

若使用 VS Code，建議安裝 Live Server 擴充功能，並以「Open with Live Server」啟動預覽。
